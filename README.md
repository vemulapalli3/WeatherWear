# WeatherWear

WeatherWear is an interactive, IoT physical data visualization system that bridges the gap between digital meteorological data and physical space. Designed as a tangible alternative to traditional smartphone applications, the model fetches real-time ambient weather data and translates it into an intuitive, physical display that suggests appropriate clothing choices for the user before going outdoors.
